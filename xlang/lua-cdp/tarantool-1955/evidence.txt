===== Scenario (reporter) =====
The UAF occurs during fiber cancellation in netbox operations:
- luaL_testcancel (fiber.c:45) builds a FiberIsCancelled exception into the diag.
- A GC-invoked lbox_fiber_cancel (fiber.c:459) clears the diagnostics, freeing
  the error.
- lbox_error (utils.c:924) / luaL_pusherror (utils.c:913) then error_ref (diag.c:100)
  the already-freed struct error -> heap-use-after-free READ of size 4.

Two distinct allocations: the LuaJIT cdata (the error handle) and the separately
allocated C `struct error`. lbox_fiber_cancel frees the struct error via the diag
while lbox_error is still ref'ing/wrapping it. NOT a borrowed pointer into a Lua
string.

Fixed for the 1.10.3 milestone (diag/error refcount + testcancel ordering).

To turn this into an OUR-captured differential a dedicated env would need a pinned
~1.10.2 source tree built with -fsanitize=address (core + bundled LuaJIT), a
driver that reproduces the netbox fiber-cancel window, and the 1.10.3 fixed tree
as the clean control.
