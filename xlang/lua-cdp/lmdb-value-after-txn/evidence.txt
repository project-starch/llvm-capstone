txn:abort() is identical: freed by mdb_txn_abort via l_abort (minilmdb.c:106).

===== CONTROL (handle:read() BEFORE the txn ends) =====

  The read happens while the txn is live: the borrowed pointer is still valid,
  the full 280000-byte value comes back correct, no ASan error.

Note: for a SMALL (single-page) value LMDB pools the dirty page onto
env->me_dpages (mdb_page_free) instead of free()ing it, so ASan sees nothing —
the same allocator-pooling that masks the free in the libdbus case. We use a
multi-page overflow value, which mdb_dpage_free() free()s outright
(!IS_OVERFLOW || mp_pages==1 -> pool, else free), giving the clean trap above.
The commit-vs-read ordering differential (identical code, only when the handle
is read differs) is the deterministic proof.
