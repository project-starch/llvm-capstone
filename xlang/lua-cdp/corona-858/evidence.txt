librtt/Rtt_PhysicsWorld.cpp — PhysicsWorld::StopWorld():
    ...
    for ( b2Body *body = fWorld->GetBodyList(), *nextBody = NULL; ... ) {
        nextBody = body->GetNext();
        // (vulnerable tree) detaches only the body's DISPLAY object; joints untouched
        ...

    }

The vulnerable tree lacks the `DestroyBody(body)` call, so ~b2World frees every
b2Joint WITHOUT Box2D invoking the destruction listener.

The listener that WOULD have severed the coupling (Rtt_PhysicsWorld.cpp:45):
    void PhysicsDestructionListener::SayGoodbye(b2Joint* joint) {
        UserdataWrapper *wrapper = (UserdataWrapper *)joint->GetUserData();
        if ( wrapper && UserdataWrapper::GetFinalizedValue() != wrapper )
            wrapper->Invalidate();     // clears the wrapper's b2Joint ref
    }
Registered via fWorld->SetDestructionListener(...) (line 134). Bulk-free skips it.
