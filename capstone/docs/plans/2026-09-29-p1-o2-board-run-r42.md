The images, the emulator records and the bitstream-independent predictions are the compiler lane's
pre-registration: `lane/compiler-p1-prereg` at `10c0e4fe`,
`docs/plans/2026-09-29-p1-cell6-board-prereg.md`, section "THE -O2 PAIR". This file adds only what
the board decides: platform, invocation, the order of the boots, and the readings specific to silicon.

## Platform

`caplifive_r42_6cbdaeeb4.bit` is resident, the platform of record by the lead's R-42 decision.

## Addendum 2026-09-29: the R-43 arm discriminator, a cell ⑥ LCC-probe variant (written before its boot)

**Why.** Cell ⑥ trapped cause 25 at VA 0x26928, the `sublet_stats.split++` load in setupLookaside's
carve loop (dev `4acfbaa4`). The audit established a false deny of a live global. It did NOT establish
which of the RTL's three cause-25 arms fired:
- the miss arm is R-43, which the query-on-miss redesign targets;
- a dead arm would be a different defect, which the redesign would not fix.

The RTL lane asked for this before spending a synthesis cycle.

**The variant.** Image `2d0efa02a6797376` (1,378,720 B, entry 0x10000), built with df484d98's recipe plus `-DSUBLET_R43_LCC_PROBE`. With the define off, the same tree reproduces df484d98 byte-for-byte, so the probe is the only difference. The probe is inlined at four sites: setupLookaside twice, memsys5Init and memsys5CarveUnsafe. Its emulator records are in
`~/capstone-artifacts/p1-O2-r43probe-2026-09-29` (source `lane/compiler-r43-lcc-probe` at `5cdb01b1`):
- canonical 340,923,519, HEAP 1344064, split=5568 mrev=37966 delin=32565 revoke=37966 init=5401,
  identical to the unprobed image event for event;
- --stats 340,970,562;
- nulling-mode 340,970,563;
- `112006 38bb59fd` and 25,010 lookasides in every arm, and split=5568 in all three: every probe read live.
 In `sublet_split` (`capstone/runtime/include/sublet/sublet.h`, the header the build compiles) every `split++` becomes:

    lcc   live, p, sel 0     node validity; its node read re-installs a live id through the LSU read tap
    and   t3, live, x0       0, data-dependent on live
    cincoffset p, p, t3      the ld's capability now waits for the lcc (R-45: LSU issue is not held
                             behind an in-flight DYN op, so without this the ld could be checked first)
    ld t0,0(p); add t0,t0,live; sd t0,0(p)

The RTL lane confirmed the premise from capstone_dyn_unit.anvil at 6cbdaeeb4:
- sel 0 sends a validity query;
- the query does a mem_ch READ of the node, which the tap installs;
- the result is 1 for a live id with a matching generation;
- simulation, r43-evict-live arm 3: LCC=1 on an evicted live alias, and the next access hit.

QEMU's sel 0 always returns 1 (helper_cslcc), so the emulator shows only that the variant is otherwise
sound. **There is no new global**: a completed run's `split` equals 5568 (--stats) exactly when every
probe read live, and any shortfall counts dead readings.

**Boot.** `board-c6var.sh` on caplifive_r42_6cbdaeeb4.bit, the same invocation as p1o2-c6: 2 MiB arena,
tables 1750285, `--stats`, the relinked k800 control.

**Readings, the RTL lane's, fixed before the boot:**
1. **The trap VANISHES** and the cell completes with its oracle: hash `112006 38bb59fd`, lookasides 25,010,
   `sublet: split=5568 mrev=37970 delin=32569 revoke=37970 init=5401`. **Reading: the MISS arm.** The node
   was live, and the redesign targets the right thing.
2. **The trap PERSISTS**: cause 25 at ANY of the four probed `ld`s (0x26878 `setupLookaside+0x470`; 0x26940 `setupLookaside`; 0x110278 `memsys5Init`; 0x110544 `memsys5CarveUnsafe`; checked by the board lane in its own disassembly). **Reading: the node is
   DEAD**, a different defect: why was a live static's node written dead? At every site the `lcc` has just
   read the node, so a deny on the next `ld` is the dead reading wherever it happens. The R-42 trap site
   is `setupLookaside+0x470`, which is 0x26878 in this image, NOT 0x26928: the function moved 188 bytes.
   Outcomes are keyed to the image hash and function offsets, never to a PC read off the unprobed image.
3. **A trap elsewhere, or a different cause: inconclusive.** For example, the probes' extra installs could
   shift evictions onto another live id. The RTL lane re-plans.

**Limits:**
- The lcc sits immediately before the access, so a vanished trap shows the node was live at that moment,
  which is what the miss-arm reading needs.
- This is one boot.
