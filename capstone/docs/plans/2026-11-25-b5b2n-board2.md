**The MISS: b5b2-cptag position 22, which is reading 21.** It read 0; the PREREG expects 1.
- Reading 21 is a cycle comparison (b5b2-cptag.S:223-227). It times `rdcycle; ld pg_cache; rdcycle` before CPTAG and
  again after, and records `slti (after - before), 3`. It is meant to show that CPTAG neither invalidates nor rewrites
  the line at rs1. Only the boolean is printed.
- Reading 20 (the value still 0x1234) and every other cptag value are exact.
- The old kit's cptag image (8e74b591…, CAPCREATE minting) read 1 here on B5b-2's seal, on board 1 and on board 3.
  The image and the bitstream have both changed since.

**The windows against the I$ lines.**
- The L1 I-cache line is 128 bits, i.e. 16 B (`CVA6ConfigIcacheLineWidth = 128`,
  `capstone_cv64a6_imafdc_sv39_config_pkg.sv:95` at 904cd9c6b).
- From the image bytes, with offsets from 0x80000000:
  - new image: before window 0x1418-0x1423 (lines 0x1410, 0x1420); after window 0x142c-0x1437 (lines 0x1420, 0x1430);
  - old image: 0x13e8 (lines 0x13e0, 0x13f0); 0x13fc (lines 0x13f0, 0x1400).
- In both images, each window enters a line not fetched before. The rtl lane's image sims agree: 70 and 54 cycles,
  each window containing a first-time I$ fetch. So on silicon, reading 21 compares two instruction-fetch misses at
  least as much as it measures the D$ line.

**Not attributed.**
- The N is small. 2 zeros in 4 against 0 in 3 is well within chance.
- The pair differs in the physical board (DRAM, refill latency) as well as in the bitstream, and a board difference
  would read the same as a bitstream difference.
- The instrument records a boolean over two I$-miss windows.

**Next.** The rtl lane builds `b5b2-cptag-diag`, a separate image; the kit image is not edited.
- It records both raw deltas, then repeats the measurement with the code warm and records that pass's deltas and flag.
- Its PREREG amendment gives sim values and H-fetch / H-line thresholds.
- The runtime lane's grant covers board 2 and board 3 with no flash. Booking waits until that amendment is pushed and
  the diag's sha256 in it matches the image loaded.
- Order per boot: the control, the original cptag ×1, then the diag ×3.
- If the warm pass reads H-fetch on both boards, reading 21 is an instrument defect. If it reads H-line anywhere, the
  runtime lane decides on the flash swap that separates board from bitstream before anything else runs.
