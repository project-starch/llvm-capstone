# R-75 silicon kit on board 2: board lane run plan (bitstream 1, then R-75 (d))

Status: written and pushed 2026-11-22, before the run. The kit, its vectors and its grading are the rtl lane's
(land/rtl-r75-kit 515d5bc97c7b, `capstone/tests/rtl-smoke/r75-bare-2026-11-22/PREREG.md`), unchanged. The order is the
runtime lane's request of 2026-11-22. This file adds the procedure only; there is no amendment to the kit.

**Bitstreams, checked locally against their seals before the run:**
- bitstream 1, `caplifive_…-pagedtbl-r76_9e801ab5e.bit`, sha256 01707b372e93ab1c…;
- R-75 (d), `caplifive_…-pagedtbl-r76-r75d_1c5d31474.bit`, sha256 2d2ba92c2e193dc4… (sealed by this lane 2026-11-22,
  full build PASS on every key, `2026-11-22-r75d-gate.md`).

Bitstream 1 is the registered default and the fallback. R-75 (d) is left resident at the end, because the runtime
lane's makerand null runs on it next.

**Images**, checked against the PREREG table before the run: va-runv f0ed3fac351b60f3 (rec 0x8000c000),
r75-trapz 311e56388094b2ad and r75-trap 73ce33d96fac8e91 (rec 0x80012000 each). The kit's SHA256SUMS passes.

**Procedure** (`<mnt-hdd>/capstone/r75kit-b2/run-r75kit.sh`):
- It waits for the runtime lane's dem-b2 chain to end, then for board 2 to be free, and books board 2 for 120 min.
- Bitstream 1: read the resident name back; if it is not bitstream 1, flash it (sha256 checked first) and read back
  again. Then one JTAG load each, through `sup-bare-2026-10-03-ladder/run_sup_bare.py` from the kit's tree (it refuses a
  resident other than the one named): va-runv, r75-trapz, r75-trap LAST, then va-runv again to re-confirm the board after
  the expected wedge. Each load's timeout is 150 s.
- R-75 (d): flash it (sha256 checked first), read back, then va-runv, r75-trapz, r75-trap, and r75-trap again in a
  separate load.
- A failed flash or readback STOPs the run before any load on an unknown resident.
- On every exit it unbooks and touches the runtime lane's marker `perf/natstage/r75kit-b2.DONE`, so the board does not
  idle.
- Its stubbed dry runs are kept beside it: `dry1` (both flashes, all eight loads), `dry-resident` (no flash),
  `dry-flashfail` (the STOP branch, still unbooking and touching the marker), `dry-nourl` (a precheck STOP).

**Grading:** the PREREG's rules, applied value by value to each load's UART SR/SV lines by `grade-r75kit.py` beside the
script.
- VOID unless all three va-runv loads read SR 15 and its 15 values.
- r75-trapz must read SR 3 `0x2 0x80004000 0x5` on both bitstreams, or the R-75 reading is VOID.
- REPRODUCED: bitstream 1's r75-trap prints no SR line. FIXED by (d): both (d) r75-trap loads read the SR 3 vector.
  NOT REPRODUCED: bitstream 1's r75-trap returns; that is a finding, not a pass.
- The grader was negative-tested before any reading, on fabricated runs for each branch: reproduced and fixed, not
  reproduced, a void control, a void matched control, (d) not fixed, and no data.
- Readings are cited by image hash.
