# B5b-1, the Sublet format in the core (Line B option C, ruled 2026-11-22): plan and pre-registrations

**Ruling.** The lead chose option (C), staged, on 2026-11-22, in the runtime lane's session (relayed by the runtime lane).
B5b-1 is the format, the record and the instructions, with CSRUNV kept and the monitor redesign that implies. B5b-2 is
the trap route, the raw tag moves and the deletions. Scope and step list: llvm-capstone land/rtl-sublet-p2,
docs/plans/2026-11-17-sublet-b5b-scope.md, "What proceeds now". Each step gets a synthesis-only gate before anything
is built on it.

**An input from the P1 cone cuts** (dev d9dde0a25034, 448b5197349f): on P1 the worst paths run through the lifetime
unit, first at its record read response and then at the D$ read grant. Both are combinational into the unit's event

response side.

## Step 1a: the codec alone, out of context (pre-registered before the run)

RTL: capstone-ariane `lineb-codec` 2fcbebf64 (on P1). core/sublet_codec.sv, `sublet_cap_compress` and
`sublet_cap_decompress`, connected to nothing in the core. It reproduces the reference model's encoder on 1,006,498
vectors, both directions, with 0 mismatches; two mutants and an altered vectors file are caught. The gate is
verif/tests/sublet-codec/synth-codec.tcl: out-of-context synth_design on the board's part, with the gate top
registering every input and output and the two modules NOT chained.

| key | prediction | if missed |
|---|---|---|
| completes under the guard | yes; mapping peak under 5 GB (a tiny design) | a blowup over 10 GB: the codec cannot enter the core as written; partition read |
| loops | 0 | named |
| compress / decompress LUT | reported per module; expected in the low thousands together (a 64-bit priority encode and the shifts of compress_bounds; the shifts and adds of decompress_bounds) | above ~10,000: the per-site cost in step 1b is re-planned before any core edit |
| timing at 20 ns, register to register | reported | |

## Step 1b: the format in the core (design next)

The lane {bounds[25:0], tag, hi 64} (CAP_MD_W 90 -> 91), the cursor as a 38-bit zero extension, the id {generation 32,
slot 31} (55 -> 63 bits at about 70 sites), R-60's window limit and the genesis range under 2^38, and the decode shim
(every decoded capability NONLIN RWX). Site census and pre-registration to follow, on bitstream 1 + R-75 option (d).
