== A METHODOLOGICAL FINDING, and it qualifies the house acceptance standard ==
# The one number that moved is the anvil exception's cycle stamp: 3648 (baseline) -> 3656 (stage 0).
# That is NOT attributable to Stage 0, because the simulation seed is RANDOM PER RUN:
# verif/sim/cva6.py:785 declares --sv_seed with default=str(random.getrandbits(31)), so unless the
# seed is passed explicitly every run draws a fresh one. This run used +ntb_random_seed=1328145522
# and the baseline's seed was never recorded.
#
# CONSEQUENCE: "zero cycle drift" -- the acceptance phrasing inherited from 054cea69b's own commit
# message -- is NOT assertable across two runs unless --sv_seed is pinned on both. Any future
# cycle-level comparison here must pass --sv_seed explicitly, and any past one that did not is
# confounded.
#
# WHAT THIS RUN DOES GIVE, and it is the stronger statement: the 19 retired writes are identical
# under a DIFFERENT random seed, so the functional result is seed-robust rather than merely
# reproducible. Register-level equality is the evidence; cycle-level equality is unavailable.
