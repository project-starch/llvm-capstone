== WHAT CHANGED ==
# The LSU's single core-wide revnode tracker, whose adopt arm asserted valid=1 for any access
# presenting a different id, is replaced by a tagged 4-way x 64-set positive validity cache filled
# ONLY by observing the rev-node unit's own node-memory traffic (a write tap and a read tap in
# ex_stage). An access is allowed only if its exact 30-bit (generation,index) is resident AND was
# last seen live. THIS REVISION DENIES ON A MISS -- see LIMITATION.

== ARM 1: THE ACCEPTANCE FIXTURE INVERTS (src/r35-rotate-stale.S) ==
# Baseline of record (sim-rotate-stale.result-lines.txt): 4 traps. M1: 7 traps.
# The three new traps are exactly the three accesses that previously succeeded through a REVOKED
# capability. Decoded from the trace, not inferred:
#   0x800001f8  0x00053c03  ld  x24,0(x10)   ARM B stale read   was 0x00a5a5a5a5a5a5a5 -> now TRAPS
#   0x80000210  0x00653023  sd  x6,0(x10)    ARM C store        was LANDED             -> now TRAPS
#   0x8000021c  0x00053d83  ld  x27,0(x10)   ARM C readback     was 0xa5               -> now TRAPS
# Six traps retire mcause 0x19 (=25 INVALID_CAPABILITY); the seventh retires 0x18 (=24), the
# pre-existing control from the host's integer-base store at 0x8000024c. All 7 accounted for.

== THE NEGATIVE CONTROLS STILL PASS -- this is not a blanket denial ==
#   0x800001f0  x23 = 0x005b5b5b5b5b5b5b   load through the LIVE sibling  -> still returns data
#   0x80000218  x27 = 0x005b5b5b5b5b5b5b   live-alias read                -> still returns data
# The second line is also independent proof ARM C's store never reached memory: in the baseline run
# that location had been overwritten to 0xa5 THROUGH THE REVOKED REFERENCE. Here it still reads
# 0x5b5b..., so the storage is uncorrupted. Refusing to retire a value and refusing to perform the
# write are different claims; this establishes both.

== LIMITATION -- WHAT THIS DOES NOT LICENSE ==
# 1. THIS REVISION DENIES ON A MISS, and a miss is not proof of revocation, only absence of proof of
#    liveness. Zero false denies HERE bounds nothing for the monitor or for SQLite: these 92
#    fixtures are small bare-metal .S tests. The named stress cases are absent -- the monitor's
#    trap prologue performs 30 plain stores through a CSCRATCH-derived capability and NO fixture
#    replicates that shape, and SQLite's entry glue performs 1,059 splits.
# 2. Fail-OPEN on a miss is not an alternative: a revoked id is cleared from liveness by the
#    invalidation broadcast, so a revoked access would MISS and be allowed -- R-35 unchanged.
#    Removing the false denies requires query-on-miss with a pre-issue stall, which is a later change.
# 3. SYNTHESIS HAS NOT RUN on this hash. Lint sees none of retiming, congestion or Vivado's own loop
#    analysis, and this adds ~8k flops plus comparators inside two modules in the UNOPTFLAT set.
# 4. r12-recl-cpmp.S is UNCHANGED, by construction rather than by luck: the privilege gates are
#    complementary (load_store_unit.sv checks == PRIV_LVL_M, pmp_data_if.sv checks != PRIV_LVL_M)
#    and that fixture runs from S-mode, so an LSU-only change cannot reach it. The CPMP tracker
#    carries the same defect shape and is knowingly untouched.
