== WHY (the after-audit's finding A) ==
Arm 6's pre-read of alias C HITS (C fresh and resident). The replay design sets the ALLOW record only from a live PROBE,
so the record never holds C, and the noclear build is denied through probe -> DEAD exactly like the shipping build.
Shipping trace of the original batch: C's pre-read "verdict LD id=00010616 hit=1 live=1 ok=0"; the arm-6 access
"hit=0 live=0 ok=0 dead=0 replay=1"; then "probe-resolved pend=00010616 tap=00020616 live=1 -> DEAD". A control that
cannot fire proves nothing. Arm 6b evicts C2 BEFORE its first read, so that read misses, probes, resolves live and
sets the record to C2; then REVOKE (the broadcast must clear the record), CHURN 256 (its DEAD entry evicted, index
reissued at generation+1), read.
