# PREREG: R-64, R-65, R-66 on silicon (bitstream 3)

Written 2026-10-27, before any board run. There are five images, one cold bare boot each. Each vector is the recorder's
words at `board_rec`, taken from simulating that image:
- on the bitstream-3 core: capstone-ariane r62-divsqrt be9a844b7, whose core/ is e7af48457's, dirty=no, `.sup/r6466b3` in vp8;

at be9a844b7, and build.sh checks them against VP_SRC. The compiler reproduces fp-rm-bare-2026-10-26's SHA256SUMS.

## Grading on bitstream 3 (caplifive_vp2c_e7af48457)

- **VOID** unless SR equals the table's count, the image hash matches SHA256SUMS, and the resident bitstream is
  caplifive_vp2c_e7af48457.
- **CONFIRMED ON SILICON:** the image reads its bitstream-3 vector exactly.
  - fp-of and fp-special confirm R-64.
  - fp-carry confirms R-65. fp-edge confirms the R-65 entries of its part 1.
  - fp-box confirms R-66, and so does fp-edge's part 2.
- **NOT ON SILICON:** the fixed-core vector. That contradicts the source, so check the resident bitstream first.
- Any other vector is a finding, graded value by value.

## Grading on a bitstream that carries r64-flags

Each image must read its fixed-core vector exactly.
