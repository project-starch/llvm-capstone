# T1 (Sublet spatial) against T2 (spatial + temporal) on silicon, bitstream 2, 2026-10-26

**Plan:** `../../PREREG-t1-t2-sampling.md`, revision 2, with its pilot-read section, written before the main run.

**Platform:** caplifive_vp2c_dcc6daf6e on both boards.
- Kits bkit10-perf: launcher 978c09d61f774315; module 9c60fb53f80ce67e = dev + `CAPSTONE_VM_BENCH_COUNTERS`, 18-bit
  flat.
- SDKs from dev 4f054964a7d8 (the heap-ids fix), one per arm. They differ only in heap.c.obj.
- Images built by `../../build.py` with the controlled layout. heap.c is linked last and padded; every other input
  section is at the same address in both arms (`check-arms.py`, 148/148 pairs).

**Records:**
- `runs-<kit>.tsv.gz` is one row per iteration, parsed from each kit's board transcript by `../../parse-board.py`.
- `steps-<kit>.tsv` is each kit's process order.
- `pilot-runs.tsv.gz` is pilot 2.
- `twin-checks.tsv` holds the bitstream-2 QEMU twin's check= value per program.

**Tables and box plots,** regenerated by the committed script:

    for k in k1 k2 k3 k4 b2k1; do zcat runs-$k.tsv.gz | tail -n +$([ $k = k1 ] && echo 1 || echo 2); done > all.tsv
    awk -F'\t' 'BEGIN{OFS="\t"} NR==1 || ($4!="ludcmp" && $4!="st") {if (NR>1 && $4 ~ /-libc$/) $3="beebs-libc"; print}' all.tsv > main.tsv
    python3 ../../perf-analyze.py report main.tsv --out . --boot 10000 --seed 20261026

**What each table holds:**
- `per-program.tsv` gives T2/T1 of cycles: exp of the difference of process-mean log cycles, Welch 95 % (lo, hi), a
  two-level bootstrap (blo, bhi), and the instret ratio.
- `per-suite.tsv` gives the geomean with a two-level bootstrap interval.
- `box-<suite>.svg` plots every timed iteration's cycles, normalised to the program's T1 median.

**ludcmp and st** are left out of the main table. Their result fails verification on silicon, natively as well as in
a context, through R-62's divide/sqrt rounding. `per-program-fpu-r62.tsv` gives their T2/T1 anyway (1.000); both arms
run identical arithmetic.

**Checks against the twin, per program:**
- 61 equal hashes;
- minver differs. That is R-62, reproduced exactly by the RTL rounding model;
- 41 programs carry no hash.
- 11 programs have neither a real verify nor a hash, so their silicon output is unchecked: fasta, miniz, miniz-libc,
  rijndael, sglib-dllist(-libc), sglib-hashtable(-libc), stb_perlin and trio-snprintf(-libc).
