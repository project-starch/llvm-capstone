505.mcf_r src.alt "capstone": research build for the Capstone virtual profile
(128-bit capability pointers, 64-bit long). Not approved by SPEC; results built
with it are not reportable.

spec_qsort/spec_qsort.c
  spec_qsort swaps elements in units of `long` when an element's size and the
  array's address are multiples of sizeof(long). mcf sorts arrays of pointers
  (and structs that hold them), so each 16-byte pointer was moved as two 8-byte
  halves and lost its capability tag; the next dereference faulted
  (cause 24 in cost_compare). The swap unit is now `void *` (spec_word_t), and
  the alignment test that chooses it uses sizeof(void *). Element contents and
  the sort order are unchanged.
