# PRE-REGISTERED predictions for the tshark safety fixtures (src/tsapp-safety.c), written
# 2026-09-25 BEFORE any fixture had run on any arm, and committed and pushed before the first
# boot. A cell whose outcome differs is a FINDING, never an edit to this file: if a prediction is
# wrong, the result says so and this file keeps the prediction that was made.
#
# The format is the FFmpeg port's (ports/ffmpeg/app/host/safety-expect.txt), judged by
# host/safety-verdict.py:
#   RETURN <hex>   the image exited with exactly this mark (fixture * 0x100000 + value)
#   RETURN *       a mark with this fixture's prefix; the value is not predictable (fixture 3 on
#                  level0 reads a byte of the next block's header)
#   FAULT oob      a bounds fault AFTER the fixture's touch line, at the target it printed
#   FAULT temporal a fault on a revoked or untagged capability, after the touch line, at the target
# LEN lines check fixture 1's printed capability length of a 64-byte g_malloc:
#   LEN arena      longer than 64 KiB (the pointer covers the rest of level0's arena)
#   LEN 64         exactly 64
#
# WHAT EACH PREDICTION RESTS ON, so a wrong one can be traced to the premise that failed:
# - the heap is runtime/level0.c: first fit, a 48-byte header BELOW each payload, forward
#   coalescing on every free, so at rest no two free blocks are adjacent. So a block freed and
#   asked for again at the same size comes back at the same address (5, 6). free writes only
#   headers, so a freed payload keeps its bytes (4).
# - shrink (CAPSTONE_LEVEL0_SHRINK) narrows each returned pointer to the bytes asked for, and
#   changes nothing else: no temporal safety (4, 5, 6 as on level0).
# - wmem (10-12): a BLOCK_FAST or BLOCK allocator carves its allocations out of one g_malloc'd
#   block (2 or 8 MiB), and every allocation carries that block's bounds on BOTH arms, since
#   level0 narrows only the block. After wmem_free_all, BLOCK_FAST keeps its first block and
#   rewinds it, and BLOCK re-initialises every block as one free chunk; either way the next
#   64-byte allocation takes the first chunk again (wmem_allocator_block_fast.c
#   wmem_block_fast_free_all; wmem_allocator_block.c wmem_block_free_all, wmem_block_init_block).
# - fixture 9: tsapp-safety.c built with tshark.c's compile command puts its two static arrays in
#   one .L_MergedGlobals (llvm-nm of the fixture-9 object, compiler b7b31421e9fa, 2026-09-25,
#   before any fixture was linked or run). FFmpeg's fixture 10, the same shape, returned
#   a0005b: the capability covers the merged group.
# - 7 and 8 are controls that do not depend on the heap: a global's and a stack array's
#   capability end at the object, as FFmpeg's fixtures 8 and 9 did on every arm.
