# Handoff history notes

This directory stores timestamped narrative notes and investigation history.

Guidelines:
- keep filenames timestamped so future sessions can reconstruct the order of reasoning,
- use this directory for exploratory findings, answer snapshots, and milestone-specific notes,
- do not treat files here as canonical current-state docs unless the current/ notes link back to them,
- keep historically useful failure notes even after the bug is fixed, but make sure the current/ notes clearly record the replacement current baseline,
- prefer deleting only obviously redundant duplicates; resolved bug narratives are still useful when they explain the root cause and the validated fix.
